## 方向命题

现有 action-conditioned WAM verifier 往往把“预测未来与真实观察不一致”压缩为单个风险分数。但相近的 discrepancy 可能来自：

1. 机器人执行确实失败；
2. 机器人执行正确、WAM 自身失配；
3. 物理执行与 WAM 都没有决定性错误，但部署观测被遮挡、冻结或含混。

三者合理干预分别倾向于 repair/replan、continue while downweighting WAM、reobserve/wait。问题价值很高，但宽泛 failure attribution、consistency decomposition 与 category-specific recovery 已有强祖先。

## 最接近成立的剩余命题

若未来保留 C02，只能把贡献限定为因果评测构造，而不是新的通用归因模型：

1. 从同一 simulator snapshot 和同一 π0.5 action chunk 分叉出 E/M/O 三种事件；
2. 在 task phase、action type、scalar WAM residual、policy confidence、horizon 和 latency 上匹配；
3. 对每个分叉实际执行 repair、reobserve、continue/downweight-WAM 三种干预；
4. 用 realized task cost 定义最优干预，用 paired intervention regret 审计 source-blind monitors。

最高 claim ceiling 只能是：在受控 same-snapshot、held-family counterfactual 中，scalar WAM discrepancy 对 runtime intervention 选择不充分。它不能声称开放世界因果归因、真实机器人安全或 WAM 必要性。

## 为什么当前不启动 GPU

用户要求的是 **新颖度严格大于 7.0 的 Idea 再实验**。本轮最高只有 7.0，且同族评审仍只是 provisional。直接启动完整训练会违反门槛，并可能只得到一个有用 benchmark 而不是足够新颖的方法论文。

## 结构性换题决定

下一轮排除本轮 13 项及此前 functional-geometry 三版失败机制，优先搜索：

- decision-adaptive WAM computation / value of computation；
- policy–world joint adaptation with an independent real anchor；
- cross-embodiment action-effect interfaces；
- VLA/WAM 之外仍满足无触觉传感约束的新问题型母方向。

只有新候选严格通过 `> 7.0`，才进入 research-refine、experiment-plan 与四卡 GPU pilot。
