### M7 — Automatic seed-count lock

      + (n−1)u_triplet
      + (n−1)u_PQ03

      + n u_seed_parity

## Deterministic GPU Accounting

Actual GPUh 对每个 physical GPU UUID 取本 run launch intervals 的 union 后求和。Charge key 是 host、physical GPU UUID、launch UUID、interval ID；同一 envelope 内 parent/child/telemetry 不重复收费，failed attempt 与 retry 完整收费。

必须存在的 disjoint atoms：

- screen 1k/5k/10k；
- conditional full-horizon trace；
- seeded kernel witness（包含在 first screen envelope，不另计）；
- B0 parity、cache、target/head/controls、C；
- triplet[seed]；
- PQ03[seed]；
- fold4[seed]；
- parity bundle[seed]；
- Stage1 300；
- conditional Stage2 200；
- 未包含在 unit 的 stage loads/teardown；
- failed attempts；
- one infrastructure retry allowance。

Fold4 cost 由 fold3 shadow kernel 按样本数推算，绝不提前打开 fold4。Conditional Stage2 在正式禁止前始终进入 complete-path projection。

## Launch Guard

每次 launch：

1. UUIDv4 intent 在个人目录原子创建，umask 077；
2. 5 秒内读取 physical GPU0..3 的 index、hardware UUID、compute PID、memory、util；
3. idle = no compute PID 且 memory≤500 MiB 且 util≤5%；
4. 能由 2/3 满足时只分配 2→3；
5. 只有同一快照四卡全部 idle 时，一个 atomic group 才能继续按 2→3→0→1 分配；
6. CUDA_VISIBLE_DEVICES 使用 hardware UUID；
7. CUDA context 后做 post-bind snapshot，验证 PID/PGID 与 UUID；
8. race/mismatch 只停止本 launch；不 attach/kill 外部 PID；
9. pilot、projection、hard8 任一 guard fail 都拒绝 launch，无 force override。

当前 GPU snapshot 只作历史证据，绝不能复用为 launch admission。

## Outcome and Retry Policy

- Screen、pilot/training、Stage1、Stage2 使用不同 sealed roots；
- stdout whitelist 只有 launch UUID、exit、GPU seconds、peak memory、nonfinite/safety boolean、artifact hash；
- stdout/stderr、metrics、videos、offline W&B 都随 phase sealed；
- seed-count reader 禁止访问 scientific path/field；
- scientific failure 不 retry；
- Stage1/2 missing 或 exception 不 retry；
- 仅允许一个 pre-Stage1、unchanged-config、same-seed、new-UUID 的 infrastructure retry；旧 attempt 永久计费；
- 所有 partial/failed artifacts 保留，不覆盖。

## Stop Conditions

立即停止且不扩大 claim：

- renewed jury 不授权；
- any input/path/env/hash mismatch；
- no qualifying checkpoint；
- C0 fail；
- C invalid；
- any selected-seed Stage1 eligibility fail；
- budget projection >7.2 或 actual approaching 8；
- missing/exception in a sealed rollout batch；
- experiment audit detects leakage、fake ground truth、score manipulation、phantom result 或 lineage break。
