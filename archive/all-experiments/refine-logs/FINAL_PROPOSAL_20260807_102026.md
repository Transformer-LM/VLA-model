## Problem Anchor

- **Bottom-line problem：** 判断 action-conditioned predictive world objective 是否会把一个 VLA 的共享动作接口表征塑造成对闭环控制真正有用的 future-sensitive representation，而不只是改善 auxiliary latent loss。
- **Must-solve bottleneck：** 既有 future-objective 工作通常把“有效未来对应关系”“任意辅助梯度带来的正则化”“action-output diversity/seed lottery”和“表征被策略实际使用”混在一起；单看 world loss、probe 或平均成功率不能回答 H1。
- **Non-goals：** 不提出新的 future objective、adapter、WAM 或 VLA；不重塑 frozen Qwen/VLM backbone；不做 planning、MBRL、视频生成、SOTA、真机或跨架构泛化；不声称 natural causal mediation、物理因果或排除了所有辅助正则化。
- **Success condition：** 严格 held-out 的 action-conditioned future target 先通过 C0 model gate；有效 future gradient 再相对 action-only B 和固定 matched deranged-target C 产生跨训练 seed 一致、至少 10pp 的 paired closed-loop gain；只有前两步通过，才允许检验 predictive projector 相对匹配 Q projector 的 placebo-relative reliance。

唯一贡献仍是一个预注册 sequential identification contract：

1. held-out future-latent predictive validity；
2. paired A/B/C controlled algorithmic treatment；
3. conditional empirical-support/action-output-matched representation reliance test。

最多支持 behavior-policy association、controlled algorithmic effect 与 task-local placebo-relative reliance。Adapter、DINO target、cache、projector、sign test 均为实现部件，不是独立贡献。

## Cardinality-aware Data Isolation

实际个人 LIBERO-10 数据中，dataset task-index 1 有 36 个 episode，task-index 8 有 35 个。原 50/30/20 且等分五 fold 会让 locked fold4 每任务只有一个 episode，episode bootstrap 退化。因此本版在重新终审前将比例冻结为：

- D_head 45%；
- D_adapter 30%；
- D_post 25%。

每个任务内按照 domain-separated SHA256 排序，并用 largest-remainder allocator 分配，不允许人工移动 episode。D_head 再按 62.5/18.75/18.75 分为 train/val/strict-test；D_post 的 fold0..4 比例为 2/9、2/9、1/9、1/9、3/9。最终每任务：

- D_head train/val/test = 10/3/3 episodes；
- D_adapter = 10 或 11 episodes；
- D_post fold0..4 = 2/2/1/1/3 episodes。

全部 episode ID 已直接写入 PGR_AUDIT_PROTOCOL.json。只保留 t+8 小于 episode length 的窗口；禁止 padding 与跨 episode target。Progress 固定为 t/(T−1)。

## Target and Preprocessing

两相机 RGB 均执行：uint8→FP32 [0,1]→短边 bicubic resize 256、antialias→center crop 224→ImageNet mean/std。DINO 严格本地加载、eval、FP32，并使用 x_norm_clstoken。

每个 camera 的未来差分为：

d_t = E(o_{t+8}) − E(o_t)。

D_head-train 独立拟合 FP64 ZCA whitening，特征值 floor 为最大特征值的 1e−6。NumPy PCG64 seed 1701 按 main、wrist 顺序生成两个 384×32 Gaussian matrix，经 reduced QR 与固定符号规范化后持久化。两个 32-D block 拼为 64-D y。

Nuisance covariate 为 current main/wrist CLS、task one-hot、progress 与 intercept。连续特征统计只来自 D_head-train。五折 episode-level cross-fitting 的 multi-output ridge 使用 alpha：

{1e−4, 1e−3, 1e−2, 1e−1, 1, 10}。

D_head-val task-equal nMSE 最低者胜；12 位相等取更强 ridge。D_head-train 使用 OOF residual；其他 split 使用在全部 D_head-train refit 后的 residual。Target 只表示 behavior-policy 下超出 current visual/task-progress nuisance 的 future association，不是 causal dynamics。

## Frozen Decoder, Controls and C0

对每个 token 使用无 affine 的 population LayerNorm，eps 1e−5；八 token 求均值后：

- Linear 2560→256 + GELU；
- exact StarVLA normalized 56-D action chunk 经 Linear 56→128 + GELU；
- concat 得到明确的 384-D；
- Linear 384→256 + GELU；
- Linear 256→64；
- 无 dropout。

动作归一化严格复现 clean Libero4in1DataConfig：前六维用 baseline dataset_statistics 的 min/max 映射到 [−1,1]，不 clip；gripper 第七维保持 identity。不得改成 mean/std 或 q01/q99。

Head 用 MSE、AdamW lr 3e−4、wd 1e−4、batch 256、最多 100 epoch、patience 10。Controls 为：

- state-only：同架构，action input 恒零；
- action-only：同架构，state input 恒零；
- current-DINO+action；
- additive state+action；
- nuisance ridge；
- task×progress-decile mean；
- zero。

nMSE 先在每任务内以固定 D_head-train target mean 为基准，再对两个任务等权。Full-vs-strongest-control 改善定义为 1−nMSE(full)/min nMSE(control)。Action 与 representation derangement degradation 定义为 nMSE(deranged)/nMSE(intact)−1。

每个 joint64 与 main32 gate 都要求：

- point effect ≥5%；
- 10,000 次 task-stratified episode-block bootstrap 的 one-sided 95% LCB >0。

Bootstrap 每 replicate 重新选择 strongest control。C0 任一失败即 H1 NO-RUN，不得训练 adapter。

## Fixed C Placebo

C 只在 D_adapter 上构造。Donor 必须 different episode、nonoverlapping window、无 fixed point、bijective，并优先匹配 task×progress-decile×action-norm-tercile。若稀疏，使用机器协议中固定的六级全局 merge hierarchy；选择第一个使所有 strata 都存在 perfect derangement 的层级，禁止局部或 outcome-driven merge。

Float64 Hungarian cost 只使用：

- target RMS norm；
- frozen identity predictive-head 的 Huber loss，delta 1。

两项用 population SD 标准化，floor 1e−8；有限 edge 再加入由 query/donor sample ID SHA256 导出的 1e−12 tie perturbation。Donor map 在训练前保存并 hash，不得重采样。

预训练 gate：

- donor/query mean target norm ratio 在 [0.9,1.1]；
- matched-C/intact mean identity Huber ratio 在 [0.9,1.1]；
- Huber saturation-rate 差不超过 5pp；
- 非双射、重复 donor、非法 edge、zero denominator 或无可行 merge 均使 C invalid。

## A/B/C Algorithm

每个 seed 的 A/B/C 共享 identity init、预生成并 hash 的 500 个 task-balanced batch、batch256。Adapter 是 rank-32 identity residual；Qwen 与 action head 永久 frozen。

- Action loss：normalized action space 的 mean L1；
- Future loss：64-D elementwise Huber delta 1 的 mean；
- optimizer：manual plain SGD，lr 1e−3，momentum 0，wd 0；
- 所有 gradient、norm、scale、update 为 FP32；
- create_graph=False；
- act+aux 合成后再做 global clip 1.0。

Auxiliary dose 使用 common B action gradient：

rho = 0.30 × ||g_B_action||，

s = clip(rho/(||g_future||+1e−12), 1e−3, 1e3)。

Future norm 或 rho 过小、scale hitting cap、dose error >1% 均计 fallback；500 batch 最多 5 次且 pass fraction 至少 99%。任何 nonfinite 立即使该 seed invalid。不得删除或替换 seed。

## Predictive Projector and Q

每 seed 使用同样本的 mean-token delta = mean(m_A−m_B)。D_post fold0/1 对 delta 与 target 各自做 task-aware nuisance ridge cross-fit；PCA/whitening W 只在 OOF delta residual 上拟合，保留 95% variance，cap 128。

B_N 是 W-space nuisance-predicted delta 的 95% energy SVD basis。Predictive ridge coefficient 从 W-space residual delta 预测 residual target；alpha {1e−4,…,1} 与 rank {4,8,16,32} 在 fold2 选择，12 位相等取低 rank、强 ridge。B_pred 先投影到 B_N 补空间再 QR。

Fold2 要求：

- incremental task-equal R² ≥0.02；
- 1,000 次 within-task episode permutation p<0.05。

每 seed 用 seed_Q=900000+1000×seed+candidate_index 生成 100 个同 rank Q，投影到 B_N 与 B_pred 的共同补空间。Fold3 只按 predeclared energy/action equivalence 与 Q point R²≤0.005 过滤，并以固定 log-ratio score、低 candidate-index tie rule 选择。无 Q 不影响 Stage1，但永久禁止 Stage2。

Rollout 仅需 h、m_A、m_B：

x = W(raw mean-token A−B delta − mu_delta)，

v_R = pinv(W) Pi_R x。

同一个 2560-D v_R 从八个 A token 各自减去。Pseudoinverse 是 rcond 1e−8 的线性 pinv，绝不恢复 mean；online DINO、progress、demonstrated action 或 teacher target 全部禁止。

## Locked Eligibility

Stage1 每个 selected seed 都必须：

- A 的 valid-target joint/main nMSE 各自比 identity、B、C 至少好 5%，episode LCB>0；
- adapter residual不超过 h RMS 的 10%；
- identity/direct-cache/hot-switch normalized-action max error <1e−6；
- C、dose、optimizer、nonfinite gate 全通过。

任一 seed 失败则禁止 Stage1；不 drop、不 replace。

Stage2 每个 seed 都必须：

- P fold4 point R²≥0.02 且 episode-bootstrap LCB>0；
- Q fold4 UCB≤0.005；
- P/Q energy 与每个 task×token action perturbation ratio 均在 [0.9,1.1]；
- nuisance overlap≤1e−3；
- A→B cache parity 与两条 reserved deterministic trace parity <1e−6；
- PCA support 与 action support gate 通过。

Fold4 每任务恰有三个 episode，并且所有 artifact、rank、Q 与 threshold 冻结后只打开一次。Stage1 可在 Stage2 ineligible 时继续；Stage2 只有所有 seed 的 Stage2 row 通过时才允许。

## Checkpoint Screen and Closed-loop Evaluation

Screen 按 1k→5k→10k，task 3/6 × states 0..4，共 30 rollouts。每个 checkpoint 的两个 task SR 各自必须在 [0.2,0.8]；合格者中 pooled SR 最接近 0.5 的胜出，相等取较早 step。无合格 checkpoint 即 NO-RUN。

统一 evaluator 语义：

- seed 7；
- 10 dummy settle actions；
- 最多 520 policy actions；
- chunk 8，开环执行完整 chunk；
- done=True 才算成功；
- horizon done=False 算失败；
- exception/missing 不得伪装成失败，也不得 impute。

10-seed 路径使用 final states 5..9；5-seed 路径使用 5..14。

Stage1 固定 300 rollouts。A−B 与 A−C 都要求 10-seed 时至少 9/10 positive，或 5-seed 时 5/5 positive；tie nonpositive；pooled gain≥10pp；每任务 mean≥0；C 不得比 B 低超过 5pp。

Stage2 条件性固定 200 rollouts。Primary SR(A_Q-removed)−SR(A_pred-removed) 使用同一 sign gate，且 mean≥10pp、每任务≥0、A_Q 在 intact A 的 5pp 内、A_pred 至少消除一半 A−B gain 且不低于 B 超过 10pp。

## Outcome Isolation

四类科学 outcome 独立密封：

1. screen：选中 checkpoint JSON 原子写入并 hash 前，不可查看 raw SR、日志、视频；
2. pilot/training：seed_count JSON hash 前，只暴露 exit、GPU seconds、peak memory、nonfinite/safety boolean 与 artifact hash；
3. Stage1：300 条完整前不生成或查看中途汇总；
4. Stage2：200 条完整前同样封存。

Stdout/stderr、metrics、视频与 offline W&B 都属于 outcome。失败 attempt 保留、计费，不删除、不覆盖。Seed-count reader 在 schema 层拒绝 sealed scientific fields。

## Deterministic GPU-hour Contract

GPUh 是本 run 在每个 physical GPU UUID 上占用区间并集的总和；父子进程与 telemetry 不重复计费，retry 使用新 launch UUID 并完整计费。

Seed-0 triplet 与 folds0–3 P/Q 是正式产物，因此 seed count 投影为：

pre_n = spent
      + (n−1) u_triplet
      + (n−1) u_PQ03
      + n u_fold4
      + n u_seed_parity
      + 500 u_roll
      + future stage load atoms
      + 0.20 GPUh retry allowance。

projection_n = pre_n + max(10%×pre_n, 0.30 GPUh)。

所有 unit 都是 1.10× 实测上界。Fold4 用 fold3 shadow timing 按样本数缩放，不能提前打开 fold4。Stage2 在尚未被 gate 禁止前必须计入 500 rollout，不得为通过预算而删掉。

自动规则：

- 每次 pilot launch 前：spent + active_remaining_UB + worst_case(next) ≤2.0；
- seed choice：projection_10≤7.2 选 10，否则 projection_5≤7.2 选 5，否则 STOP；
- seed count 冻结后每次 launch 重新要求 selected projection≤7.2；
- actual GPUh 永远不超过 8.0；watchdog 只可终止本 launch 的 PGID，并预留 0.05 GPUh teardown margin；
- 无 force override。

Pilot 最多只能支持 feasibility、C0、optimizer/PQ feasibility 与 timing，不能产生 C1 或 C2 claim。

## Claim Ceiling

若完整通过，只允许表述：

> 在一个 treatment-blind-selected 的 deterministic StarVLA checkpoint 和两个预注册 LIBERO tasks 上，valid-target gradient algorithm 相对 action-only B 与一个固定 scalar-dose-matched deranged-target C 产生 seed-consistent closed-loop gain；移除一个 offline-learned、nuisance-annihilated、rollout-available predictive projector，比移除 empirical-support/action-output-matched Q projector 更伤害性能，为 task-local placebo-relative reliance 提供证据。

Stage1-only 只能作 controlled algorithmic contrast。任何 negative gate 都缩窄或停止 claim；预算失败是 NO-RUN，绝不是删除 control 的理由。
