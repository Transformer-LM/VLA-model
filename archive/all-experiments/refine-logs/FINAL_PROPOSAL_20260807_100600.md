# Research Proposal: PGR-Audit

## Problem Anchor

- **Bottom-line problem：** 判断 action-conditioned predictive world objective 是否会把一个 VLA 的共享动作接口表征塑造成对闭环控制真正有用的 future-sensitive representation，而不只是改善一个 auxiliary latent loss。
- **Must-solve bottleneck：** 既有 future-objective 工作通常把“有效未来对应关系”“任意辅助梯度带来的正则化”“action-output diversity/seed lottery”和“表征被策略实际使用”混在一起；单看 world loss、probe 或平均成功率不能回答 H1。
- **Non-goals：** 不提出新的 future objective、adapter、WAM 或 VLA；不重塑 frozen Qwen/VLM backbone；不做 planning、MBRL、视频生成、SOTA、真机或跨架构泛化；不声称 natural causal mediation、物理因果或排除了所有辅助正则化。
- **Constraints：** frozen Qwen3-VL-4B 与 frozen deterministic MLPResNet action head；个人离线 LIBERO 数据、DINOv2 和 StarVLA checkpoint；所有远程产物仅在 '<PERSONAL_RESEARCH_ROOT>'；物理 GPU 2/3 优先，0/1 仅在四卡均空闲时使用；总计不超过 8 GPUh，完整路径投影不超过 7.2 GPUh；不得接触团队/共享目录或脏 CF-DynAlign 树。
- **Success condition：** 一个严格 held-out 的 action-conditioned future target 先通过 model gate；随后有效 future gradient 相对 stop-gradient 和 matched deranged-future placebo 产生跨训练 seed 一致、至少 10pp 的 paired closed-loop gain；若继续做机制层，cross-fitted predictive-component removal 必须比 action-output-matched orthogonal placebo 更明显地消除该 gain。

## Method Thesis and Contribution

唯一贡献是一个预注册 sequential identification contract：

1. held-out future-latent predictive-validity；
2. paired A/B/C algorithmic treatment；
3. conditional empirical-support/action-output-matched representation reliance test。

最多支持 behavior-policy association、controlled algorithmic effect 与 task-local placebo-relative reliance。Adapter、DINO target、cache、projector、sign test 均为实现部件，不是独立贡献。

## Data Isolation and Target

For each of the two tasks, episodes are stratified by SHA256(task_id|episode_id|1701):

- D_head 50%；
- D_adapter 30%；
- D_post 20%。

Every partition and every D_post fold must contain both tasks；D_head/D_adapter/D_post each need at least three episodes per task。Any t+8 crossing episode end is dropped；terminal clip padding is forbidden。

D_head is split 70/15/15 train/val/strict-test。D_post roles are immutable：

- folds 0–1: mechanism/nuisance fit；
- fold 2: ridge/rank validation；
- fold 3: Q calibration；
- fold 4: locked one-time final gate。

For main and wrist cameras:

\[
d_t^c=E_c(o_{t+8})-E_c(o_t).
\]

Whitening is fit only on D_head-train。Each camera uses a fixed seed-1701 orthonormal 384→32 projection；the two blocks form y∈R64。Remove current-state nuisance using a cross-fitted linear ridge:

\[
z=[E_{main}(o_t),E_{wrist}(o_t),task,progress],\qquad r=y-b(z).
\]

The target is therefore a future association beyond current visual/task-progress nuisance under the behavior policy—not causal dynamics。

## Frozen Decoder and Predictive Gate

Decoder:

- mean-pooled LN(m)→256；
- normalized 56-D action chunk→128；
- concat→256→64 GELU MLP；
- no dropout。

Head seed1701；AdamW lr3e-4，wd1e-4，batch256，max100 epochs，patience10，best val nMSE tie earliest。After training, decoder、nuisance、whitening、projections、splits、preprocessing and config are frozen and hashed。

Schedule-matched controls: state-only，action-only，current-DINO+action，additive state+action，nuisance/task-progress/zero。On D_head strict-test，full q(m,a) must on joint64 and main32 independently：

- improve nMSE over strongest control by at least 5%；
- one-sided episode-bootstrap LCB>0；
- stratified action derangement and cross-episode representation derangement each worsen nMSE by at least 5% with LCB>0。

Failure is NO-RUN。

## Fixed C Placebo

On D_adapter, C donors must be different-episode, nonoverlapping-window, no-fixed-point and matched within task×progress-decile×action-norm-tercile。Fixed minimum-cost matching uses only target norm and identity-head Huber loss；sparse bins merge in a fixed order。Before training, C/A target-norm and identity-loss ratios must lie in [0.9,1.1] and Huber saturation-rate difference ≤5pp。No outcome-driven resampling。

## A/B/C Algorithm

Per seed, arms share identity initialization、batch order、500 steps、batch256。Adapter optimizer: plain SGD lr1e-3，momentum0，wd0，global clip1.0。

FP32, create_graph=False, detached scales:

\[
g_j^{act}=\nabla L_{action},\quad
g_A^{fut}=\nabla L_{future}(q(m_A,a),r),\quad
g_C^{fut}=\nabla L_{future}(q(m_C,a),\pi(r)).
\]

\[
\rho=.30\lVert g_B^{act}\rVert,\qquad
s_j=clip(\rho/(\lVert g_j^{fut}\rVert+10^{-12}),10^{-3},10^3).
\]

\[
g_A=g_A^{act}+s_Ag_A^{fut},\quad
g_B=g_B^{act},\quad
g_C=g_C^{act}+s_Cg_C^{fut}.
\]

B logs the same frozen future forward/loss but receives no auxiliary update。A/C dose error≤1%；nonfinite stops；scale/zero fallback≤1%；≥99% batches pass。Log loss、gradient cosine/norm、clip/update、adapter residual and action-output diversity/effective rank。

## Predictive Projector and Q

For each seed:

\[
\bar\delta=\frac1{8}\sum_k(m_A^k-m_B^k)\in\mathbb R^{2560}.
\]

Offline folds0–1 use z=[current DINO, demonstrated action, task, progress] only to cross-fit residual delta/target。Fit PCA/whitening \(W:R^{2560}\to R^d\) on residual delta，95% variance，d≤128。Ridge-RRR grids: ridge {1e-4,1e-3,1e-2,1e-1,1}, rank {4,8,16,32}；fold2 lowest nMSE，tie lower rank/stronger ridge。

Let B_N span whitened nuisance-predictable delta。Project RRR basis into its complement and orthonormalize B_pred：

\[
\Pi_{pred}=B_{pred}B_{pred}^\top,\qquad
\lVert B_{pred}^\top B_N\rVert_F/\sqrt r\le10^{-3}.
\]

Fold2 requires incremental R²≥.02 and 1,000 episode-block permutation p<.05。

Generate 100 fixed-seed B_Q in the same empirical span，orthogonal to B_pred/B_N，same rank；\(\Pi_Q=B_QB_Q^\top\)。Fold3 selects a candidate with removed-energy and per-task/per-token action-output perturbation ratios in [.9,1.1] and nuisance overlap≤1e-3。All artifacts freeze/hash before fold4。

Rollout needs only h, m_A and m_B:

\[
x=W(\bar\delta-\mu_\delta),\quad
v_{pred}=W^+\Pi_{pred}x,\quad
v_Q=W^+\Pi_Qx.
\]

W+ is only the linear pseudoinverse and never restores the mean。Apply the same 2560-D vector to each token：\(m_{A,-pred}^k=m_A^k-v_{pred}\)，analogously Q。No online DINO、progress or demonstrated action。

## Locked Per-Seed Eligibility

Fold4 opens once after all artifacts freeze。

Stage-1 eligibility for every selected seed:

- A correct-target joint/main nMSE beats identity/B/C≥5%，episode LCB>0；
- adapter residual≤10% h RMS；
- cache/direct/hot-switch parity<1e-6；
- C/dose/optimization gates pass。

Any seed failure forbids Stage1；no drop/replacement。

Stage-2 eligibility for every seed:

- P point R²≥.02 and episode-bootstrap LCB>0；
- Q episode-bootstrap UCB≤.005；
- P/Q energy/action-output ratios [.9,1.1]；
- nuisance overlap≤1e-3；
- A→B cached and two reserved deterministic-trace action parity<1e-6；
- interpolation support stays within fold4 99th-percentile PCA distance and training action range。

Stage1 may run if all Stage1 rows pass even when a Stage2 row fails；but Stage2 is globally forbidden unless all Stage2 rows pass。
