# Novelty / Scoop Check：OA-WAM × EvoScene 对象 belief

**日期**：2026-08-29  
**评审路由**：多源检索 + 官方全文 + same-family independent reviewer（provisional）

## Verdict

**Level 2 — High Overlap**。宽版“对象地址 + action-updated belief + observation correction + verifier/recovery”被 OA-WAM、EvoScene、RB-VLA、Embodied-SlotSSM、CheckVLA 与 POT-VLA 的并集高度覆盖。仅保留一个窄机制进入证伪：自然执行动作产生的 per-candidate action-effect likelihood 是否能帮助遮挡后对象身份关联。

## Delta

> Unlike Object Permanence Filter / impact-aware tracking, which use object dynamics to preserve pose tracks, and OA-WAM / Chameleon, which preserve object or control-relevant identities from visual history, the proposed pilot uses naturally executed task actions to form a per-address, per-detection response likelihood for multi-hypothesis identity association, and measures whether this extra evidence reduces wrong-object decisions beyond appearance, pose and flow.

## Decomposed claim

- **Problem framing**：相似对象在操作、遮挡、交叉和重现后，VLA 可能把语言目标与错误实例绑定。
- **Core mechanism**：对每个 address–detection 候选计算已执行动作下的 action-effect likelihood，并做 Bayesian identity update。
- **Key insight**：任务本身自然产生的动作是一次“免费干预”；哪个对象按预期响应，可能包含静态外观/位置以外的身份证据。
- **Application domain**：长时、对象级、部分可观测机器人操作；冻结 VLA 的 belief sidecar。

## Structured closest papers

### OA-WAM (2605.06481, 2026-05)
- Problem：语言目标对象 binding 与跨视觉变化泛化。
- Mechanism：冻结对象 address + 动态 content/pose；逐对象 next-slot supervision + action chunk head。
- Insight：把身份 key 与动态内容分离。
- Overlap：3/4；不做地址错误恢复或多假设 action-effect association。
- Source：https://arxiv.org/html/2605.06481

### EvoScene-VLA (2605.21862, 2026-05/08)
- Problem：action chunk 之间缺少动作更新的 scene prior。
- Mechanism：action expert 预测 recurrent scene state，新观测纠正 prior。
- Insight：执行动作应改变下次 VLA 调用前的 scene belief。
- Overlap：3/4；其 belief 是匿名全局 latent，不做对象身份 posterior。
- Source：https://arxiv.org/html/2605.21862

### Object Permanence Filter (2403.08231, ICRA 2024)
- Problem：多对象、长遮挡和不可靠测量下的 tracking。
- Mechanism：per-object particle filters，dynamics/occluder/uncertainty update；支持多假设和 closed-loop feedback。
- Insight：缺测时应预测并增加不确定性，而不是丢失对象。
- Overlap：3/4；不使用机器人已执行动作作为 address–detection identity likelihood。
- Source：https://arxiv.org/html/2403.08231

### Impact-Aware Object Tracking (T-RO 2024)
- Problem：碰撞后的 6D object tracking。
- Mechanism：把已知碰撞/摩擦动力学纳入 particle filtering。
- Insight：事件特定动力学先验能提高 tracking。
- Overlap：3/4；单对象 pose tracking，不做语言地址、多对象身份 posterior 或 VLA 决策。
- Source：https://github.com/MaartenJongeneel/Paper-Tracking

### Chameleon (2603.24576, 2026-03)
- Problem：observation–action delay 与遮挡后控制相关身份记忆。
- Mechanism：event traces、control-indexed recall、Control-JEPA。
- Insight：记忆必须可分、可寻址、可供未来控制使用。
- Overlap：2/4；不显式计算对象候选的 action-effect likelihood。
- Source：https://arxiv.org/html/2603.24576

### Embodied-SlotSSM (2511.11478, 2025-11)
- Problem：对象级非马尔可夫操作。
- Mechanism：持久 slots、关系编码、temporal identity supervision。
- Insight：memory state 应以对象为单位演进。
- Overlap：3/4；没有 executed-action likelihood 的数据关联。
- Source：https://arxiv.org/html/2511.11478

### RB-VLA (2602.20659, 2026-02)
- Problem：长时部分可观测 VLA 的进度丢失。
- Mechanism：action/history-conditioned compact stochastic belief。
- Insight：action-conditioned belief 比短窗口历史更适合闭环。
- Overlap：2/4；belief 为全局 latent。
- Source：https://arxiv.org/html/2602.20659

### Reflective VLA (2606.25215, 2026-06)
- Problem：部署变化需要从 interaction consequence 识别隐变量。
- Mechanism：把 `(O,A,O')` causal triplets 放入上下文。
- Insight：action consequence 比同长度 history 更有信息。
- Overlap：2/4；不预测 per-object effect，也不估计 identity posterior。
- Source：https://arxiv.org/html/2606.25215

### POT-VLA (2607.18016, 2026-07)
- Problem：长时对象状态、谓词验证、失败恢复。
- Mechanism：persistent RGB-D role object records + predicate verifier + retry/reobserve/reground/replan。
- Insight：执行必须围绕共享、可验证的对象状态闭环。
- Overlap：3/4；没有 learned action-conditioned identity likelihood。
- Source：https://arxiv.org/html/2607.18016

### CheckVLA (2607.26789, 2026-07)
- Problem：执行后偏差的检测和动作后缀修复。
- Mechanism：action-conditioned latent prediction、真实观察比较、校准 intervention。
- Insight：预测—观测残差可触发恢复。
- Overlap：2/4；全局 residual，不做身份关联。
- Source：https://arxiv.org/html/2607.26789

### ProbeAct (2606.09740, 2026-06)
- Problem：冻结 VLA 的抓取/搬运/放置失败检测和恢复。
- Mechanism：对象 3D probe + Hungarian identity matching + kinematic state machine + CBF correction。
- Insight：VLA hidden state 和机器人运动学可提供轻量 runtime safety net。
- Overlap：2/4；不做 action-conditioned identity posterior。
- Source：https://arxiv.org/html/2606.09740

### Procedural Mistake Detection via Action Effect Modeling (2512.03474, ICLR 2026)
- Problem：程序视频中的错误往往体现在结果而非动作外观。
- Mechanism：effect-frame selection + visual grounding + scene graph effect representation。
- Insight：action effect 对错误检测有独立价值。
- Overlap：2/4；人类视频诊断，不做机器人对象身份或闭环 belief。
- Source：https://arxiv.org/html/2512.03474

## Pilot gate

先在 oracle state 下估计：

`I(identity ; action-effect | appearance, pose, optical/scene flow)`

并比较完整组合基线。若 IDF1 提升 <5pp、条件互信息接近零，或不能降低 wrong-object action，则停止，不训练完整 WAM/VLA。
