## Ranked Ideas

### 1. Interaction Fingerprints for Identity Recovery — RECOMMENDED PILOT

- **Method**：对任务自然执行的 action chunk，计算每个对象地址—检测候选应产生的响应 likelihood；在对象遮挡后重现或交叉时，把该 likelihood 与 appearance/pose/flow 联合做多假设身份更新。
- **Hypothesis**：action effect 在 appearance、pose 和 flow 之外仍包含可测的 identity information，并减少 wrong-object decisions。
- **Pilot**：先用 simulator oracle state + analytic Gaussian effect model；不训练大网络、不微调 π0.5。
- **Novelty**：6/10；Level 2 High Overlap；最近邻 OPF、Impact-Aware Tracking、OA-WAM、Chameleon。
- **Feasibility**：9/10。
- **Risk**：MEDIUM-HIGH；信息可能被 pose/flow 完全包含。
- **Positive signal**：组合基线之上 IDF1 ≥5pp，条件互信息显著大于零，并降低 wrong-object action。
- **Next**：通过后才训练 learned action-effect predictor，再接冻结 π0.5。

### 2. Non-target Objects as Concurrent Negative Controls

- **Method**：由动作模型预测哪些对象应保持不变；利用其共同 residual 区分相机/光照共模偏移、target-only failure 和 pairwise ID swap。
- **Novelty / impact / feasibility**：6 / 6 / 9。
- **Status**：CAUTION；作为 Idea 1 的 nuisance robustness 与 attribution ablation。
- **Kill**：不优于 camera compensation + matched all-object classifier。
