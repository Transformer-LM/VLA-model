# OA-WAM × EvoScene-VLA 机制候选池

**生成时间**：2026-08-29 22:28  
**生成方式**：两个独立只读发散分片 + 主执行器机械去重  
**规则**：本文件不做最终排序；只合并同义项并标注客观资源与最近邻冲突。

## C1｜OAPCC：对象可寻址预测—比较—纠正 belief

- **方法**：为每个语言对象地址维护状态/关系/可见性 belief；根据实际执行 action chunk 预测 per-address prior；将新 slots 与地址软关联，计算对象级 innovation；只纠正证据支持的变量，并输出执行失败、身份错配、不可观测三类后验。
- **假设**：同等全局 prediction error 下，它比 global recurrent belief 或全局 verifier 更少错误覆盖任务进度，并改善下一决策。
- **最小 pilot**：LIBERO/RoboTwin 的 oracle object ID/pose transitions；注入 no-op、ID swap、occlusion；冻结 π0.5，只训练轻量 belief head。
- **基线**：current observation；matched global GRU/Transformer；global action-conditioned belief；persistent slots without action；direct verifier；POT-VLA-style rules。
- **指标**：归因 macro-F1、ID switch、relation/progress F1、ECE/Brier、错误干预率、闭环成功率。
- **kill**：oracle slots 下相对 matched global belief 的归因增益 <3pp，或 direct verifier 同样有效，或不改善决策。
- **最近邻**：OA-WAM、EvoScene、RB-VLA、Embodied-SlotSSM、CheckVLA、POT-VLA。
- **客观可行性**：通过；首轮 4–8 A100h，闭环后续 8–20 A100h。
- **dedup_key**：`per_address_action_innovation_filter`

## C2｜Interaction Fingerprints：用动作效果恢复对象身份

- **方法**：预测每个身份候选在已执行动作下的 effect likelihood；重现/交叉时联合外观、几何和动作响应更新身份 posterior；证据不足时保留多假设。
- **假设**：对于同形同色对象，“哪个对象响应了动作”比静态 embedding 更能恢复身份。
- **最小 pilot**：ManiSkill/RoboTwin 的 push–occlude–reappear 与 pick–swap；只用 GT ID 评价。
- **基线**：DINO/SAM、3D pose matching、无动作 slot transformer、全局 action history。
- **指标**：IDF1、posterior NLL/ECE、wrong-object rate、闭环成功率。
- **kill**：动作效果相对 optical/scene flow 或 pose baseline 提升 <5pp。
- **最近邻**：action-conditioned tracking、causal object discovery、Chameleon。
- **客观可行性**：通过；4–12 A100h。
- **dedup_key**：`action_effect_identity_fingerprint`

## C3｜Object-Scoped Belief Repair：局部关系失效与修复

- **方法**：用动作模型预测本 chunk 应改变的对象/关系集合；按 innovation 定位受影响节点/边；仅撤销对应进度并局部 retry/reobserve，保留其余已完成事实。
- **假设**：相对 global reset/replan，可减少级联污染和重复完成步骤。
- **最小 pilot**：在长链任务中注入单对象 no-op、位移和 relation invalidation；所有方法共用同一 detector。
- **基线**：global latent correction、CheckVLA、POT-VLA、HELM、full replan。
- **指标**：collateral corruption、invalidation F1、恢复步数、重复步骤、最终成功率。
- **kill**：重做步骤下降 <25%，或手写 predicate 等价。
- **最近邻**：POT-VLA、HELM、HarnessWAM、CheckVLA。
- **客观可行性**：通过；16–36 A100h，但方法创新高度依赖 C1。
- **dedup_key**：`object_scoped_belief_repair`

## C4｜多假设对象 belief 与风险感知再观察

- **方法**：遮挡时保留 top-K 地址—slot 假设；在各身份假设下评估下一动作错误对象风险；风险高时主动 move-camera/wait/reveal，再收缩后验。
- **假设**：比 MAP identity 更安全，比始终 reobserve 更少停滞。
- **最小 pilot**：相同外观 reveal-then-manipulate benchmark；动作集合限制为 continue/reobserve/manipulate。
- **基线**：MAP、always/never reobserve、confidence threshold、generic active perception。
- **指标**：wrong-object rate、risk–coverage、ECE、额外观察数、stagnation、完成时间。
- **kill**：始终 reobserve 在匹配成本下不差，或多假设仍无法校准。
- **最近邻**：Belief Scene Graph、active perception、POT-VLA uncertain state。
- **客观可行性**：通过；8–20 A100h。
- **dedup_key**：`multi_hypothesis_identity_reobserve`

## C5｜对象记忆污染隔离

- **方法**：程序化注入 address swap、stale slot、漏检和 pose 错误；训练 action-prior consistency gate；不可信证据进入 quarantine，直到后续证据确认或丢弃。
- **假设**：一次错误 observation write 的污染会级联，而对象级隔离能缩短错误半衰期。
- **最小 pilot**：controlled memory corruption suite，冻结 VLA。
- **基线**：direct write、global recurrent memory、generic noise augmentation、full reset。
- **指标**：corruption amplification、recovery half-life、干净性能、进度准确率、错误对象操作率。
- **kill**：真实 detector errors 上增益 <3pp，或通用 augmentation 等价。
- **最近邻**：robust filtering、memory dropout、CheckVLA。
- **客观可行性**：通过；6–18 A100h；可能更像 benchmark + robustness component。
- **dedup_key**：`object_memory_poison_quarantine`

## C6｜关系 innovation 反向帮助身份绑定

- **方法**：预测 grasped-by/inside/supported-by 等关系的新增、保持、失效；选择最能解释预期关系变化的 identity assignment；联合更新身份与进度。
- **假设**：pose/appearance 含混时，动作诱发关系变化提供额外身份证据。
- **最小 pilot**：container/stacking/drawer，加入相同外观干扰物和遮挡交换。
- **基线**：appearance+pose、OA-WAM、scene-graph memory、POT-VLA predicates、无关系的对象动力学。
- **指标**：IDF1、relation event F1/ECE、false-completion、闭环成功率。
- **kill**：GT relation oracle 都无 headroom，或手写 predicates 等价。
- **最近邻**：relational object dynamics、POT-VLA、scene graph memory。
- **客观可行性**：通过；15–35 A100h。
- **dedup_key**：`relation_innovation_identity_binding`

## C7｜竞争生成解释的异常归因

- **方法**：对动作失败、地址置换、不可观测三个假设分别计算观测条件似然；归一化得到原因 posterior；用于 retry/reground/reobserve。
- **假设**：竞争生成解释比监督三分类器更能泛化到未见扰动强度。
- **最小 pilot**：离线成对反事实，留一任务/扰动强度测试。
- **基线**：三分类 MLP、global/object residual、ensemble disagreement。
- **指标**：OOD macro-F1、NLL/Brier、risk–coverage、恢复代价。
- **kill**：不能胜过同容量直接分类器。
- **最近邻**：multiple-model filters、failure diagnosis、WAM uncertainty。
- **客观可行性**：通过；12–30 A100h。
- **dedup_key**：`competing_hypothesis_attribution`

## C8｜遮挡期延迟创新账本

- **方法**：遮挡期间用动作推进 belief，将关系事件标为 pending；禁止低置信观测覆写；对象重现后做 fixed-lag smoothing，确认或撤销历史进度。
- **假设**：延迟确认同时减少 false completion 和过度保守停滞。
- **最小 pilot**：2/4/8 chunk 遮挡，遮挡期加入 success/no-op/slip。
- **基线**：current overwrite、global prior、persistent slots、rollout without retrospective correction。
- **指标**：重现后状态、relation F1、false completion、stagnation、success。
- **kill**：false completion 降低不足 20%，或停滞显著上升。
- **最近邻**：fixed-lag filtering、POT-VLA invisible records、object memory。
- **客观可行性**：通过；6–16 A100h。
- **dedup_key**：`occlusion_delayed_innovation_ledger`

## C9｜对象关系级 chunk 内 failure change-point

- **方法**：预测 chunk 内对象/关系事件轨迹；流式定位首个异常对象、关系和子步；保留已验证前缀，只重采样失败后缀。
- **假设**：比 chunk-level failure detection 减少恢复动作和重复进度。
- **最小 pilot**：在 chunk 早/中/晚注入 gripper no-op、slip、EE perturbation。
- **基线**：full replan、chunk abort、CheckVLA、continuous pose residual、oracle failure time。
- **指标**：change-point error、prefix retention、恢复步数、重复步骤、成功率。
- **kill**：定位误差 > chunk 的 25%，或不优于 full replan。
- **最近邻**：CheckVLA suffix repair；差异只剩关系事件定位。
- **客观可行性**：通过；20–40 A100h；查新风险高。
- **dedup_key**：`relation_event_changepoint_repair`

## C10｜非目标对象作为同期 negative controls

- **方法**：同时预测目标与未受动作作用对象；共同 innovation 解释为相机/光照/感知漂移，目标特异 innovation 解释为 action-effect failure，成对交换解释为 ID mismatch。
- **假设**：同场景 negative controls 能在残差幅度匹配时降低视觉偏移导致的错误失败告警。
- **最小 pilot**：相机微移/曝光、目标 no-op/slip、地址交换三类等残差数据。
- **基线**：global residual、target-only residual、camera compensation、direct classifier。
- **指标**：macro-F1、false alarm、failure recall、swap detection、ECE、错误干预。
- **kill**：未见相机变化下 false alarm 降低不足 20%，或增益仅来自参数量。
- **最近邻**：background-motion compensation、causal negative controls、多对象 WMs。
- **客观可行性**：通过；6–10 A100h 单种子。
- **dedup_key**：`non_target_object_innovation_controls`

## C11｜归因后验驱动恢复路由

- **方法**：把 C1/C7 后验映射到 retry、reground、reobserve；不收敛再升级 replan。
- **假设**：专用恢复比统一 retry/replan 成本更低。
- **最小 pilot**：先做 oracle reason routing upper bound，再替换学习归因器。
- **基线**：always retry/replan/reobserve、POT-VLA、HELM。
- **指标**：路由准确率、恢复率、额外动作、不必要干预、success。
- **kill**：oracle routing 相对最佳统一恢复提升 <3pp 且动作成本下降 <10%。
- **最近邻**：POT-VLA/HarnessWAM 已有这些原语；本候选不能单独作为主创新。
- **客观可行性**：通过；2–6 A100h，但归类为 C1 下游价值测试。
- **dedup_key**：`posterior_recovery_router`
