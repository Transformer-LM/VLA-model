# Experiment Plan

**Problem**：遮挡/交叉后，对象级 VLA belief 会把任务进度绑定到错误实例。  
**Method Thesis**：由自然任务动作形成的对象特定物理响应指纹，可为对象地址恢复提供超出外观、位姿和共享动力学的证据。  
**日期**：2026-08-29

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|---|---|---|---|
| C1：指纹提供额外身份信息 | 决定 OA-WAM 地址与 action-updated belief 是否值得结合 | 对最强组合基线 ID accuracy/IDF1 +5pp；wrong-object rate 下降；3 seeds CI 不跨零 | B1, B2, B4 |
| C2：学习指纹而非 oracle 才可部署 | 防止只证明完美模拟器有用 | learned 保留 oracle 增益 >=50%，校准不劣化 | B2, B3 |
| Anti：收益不是更多参数/历史 | 排除普通 tracker 或容量效应 | matched MLP/history 基线无同等收益；同物性负对照不产生虚假增益 | B3 |

## Paper Storyline

- 主文必须证明：条件信息存在、可学习、能改变对象选择决策。
- 附录可支持：相机共模扰动下 non-target negative control、更多物体数与更长遮挡。
- 明确砍掉：RGB 视频生成、完整 OA-WAM 复现、pi0.5 微调、自动恢复、真实机器人。
- 本阶段不依赖 frontier foundation model；这是有意的机制隔离，不强行加入 VLM/扩散模型。

## Experiment Blocks

### B1：MuJoCo oracle 可辨识性上界

- Claim tested：C1。
- Why：若完美物理指纹也不能超过 pose/velocity/shared-dynamics 基线，学习 WAM 没有必要。
- Dataset / task：MuJoCo 随机多对象推动；2/3/4 个视觉相同刚体；随机布局、空间推动轨迹、遮挡长度、交叉；homogeneous 与 heterogeneous mass/friction 两组。
- Compared systems：nearest pose；constant-velocity MHT；shared action-conditioned dynamics；oracle per-object physical fingerprint。
- Metrics：assignment accuracy、ID switches、posterior NLL/ECE、wrong-object decision rate、risk-coverage；按 crossing/occlusion/physics gap 分层。
- Setup：不少于 20k 训练/校准事件与 10k 测试事件；模拟器身份是真值；3 数据种子。
- Success：困难 heterogeneous split 相对 shared-dynamics >=5pp，bootstrap 95% CI 不跨零；homogeneous split 不出现虚假大增益。
- Failure：停止 learned WAM 与 VLA 集成。
- Target：Table 1 / Figure 2。
- Priority：MUST-RUN。

### B2：学习出的概率 action-effect predictor

- Claim tested：C1, C2。
- Why：把 oracle 上界变成可部署模块。
- Dataset / split：B1 轨迹；训练对象物性范围与未见组合 OOD split 分离。
- Systems：shared MLP；fingerprint-conditioned MLP；matched-capacity history MLP；oracle upper bound。
- Metrics：动作后状态 NLL/RMSE、assignment accuracy、IDF1 proxy、wrong-object rate、ECE、risk-coverage。
- Setup：相同 encoder/optimizer/steps；仅条件变量不同；3 seeds；GPU 2/3 优先，0/1 仅空闲时并行。
- Success：learned variant 保留 oracle 增益 >=50%，且相对 matched shared/history 基线 >=5pp 或错误率相对下降 >=20%。
- Failure：若 oracle 有效而 learned 无效，结论为可辨识但当前表示/监督不足；不接 pi0.5。
- Target：Table 2。
- Priority：MUST-RUN（仅 B1 通过后）。

### B3：反解释与简洁性消融

- Claim tested：Anti-claim, C2。
- Compared systems：去掉 `phi_i`；打乱 `phi_i`；增加历史但无指纹；增大 shared MLP 参数；homogeneous physics；不使用 action。
- Metrics：同 B2，重点为增益差、NLL 与拒绝率。
- Success：正确指纹显著优于 shuffled/no-fingerprint，matched capacity 不复现收益。
- Failure：若更大 history MLP 等价，主张退化为普通历史建模并停止。
- Target：Table 3。
- Priority：MUST-RUN（B2 通过后）。

### B4：冻结策略的对象选择代理闭环

- Claim tested：C1 的控制后果。
- Dataset / task：多类场景模板：目标推动到区域、从相似容器中取回、遮挡后继续操作；策略输出由预记录/脚本动作提供，belief 只决定目标地址，不优化控制器。
- Systems：hard nearest tracking；shared-dynamics posterior；IFB posterior；oracle identity。
- Metrics：wrong-object action、task success、abstention、恢复观察次数、步数。
- Success：不显著增加停滞的条件下，wrong-object action 相对下降 >=20%。
- Failure：ID 指标不转化为决策收益，则不值得接入 VLA。
- Target：Table 4 / qualitative rollouts。
- Priority：MUST-RUN（B2 通过后）。

### B5：共模扰动负对照

- Claim tested：支持性鲁棒性，不是主创新。
- Setup：相机平移/测量偏差同时作用于多个对象；比较 camera compensation、all-object residual classifier、non-target concurrent controls。
- Success：控制错误干预率相对降低 >=20%。
- Priority：NICE-TO-HAVE。

## Run Order and Milestones

| Milestone | Goal | Runs | Decision Gate | Cost | Risk |
|---|---|---|---|---|---|
| M0 | 数据/身份/指标 sanity | 200 小样本 + 可视化/断言 | 无身份泄漏；随机排列约为 chance；oracle 在构造样例可恢复 | CPU <0.5h | 模拟代码泄漏 object id |
| M1 | Oracle 信息上界 | B1, 3 seeds | >=5pp 且决策指标改善，否则 KILL | CPU 1–3h | 场景过易或过度手工化 |
| M2 | Learned predictor | shared/fingerprint/history × 3 seeds | learned 保留 >=50% oracle gain | 约 8–20 GPUh | 小模型 GPU 利用率低；用并行 seeds 而非扩大模型 |
| M3 | 反解释 | B3 | shuffled/capacity 不能解释收益 | 约 4–10 GPUh | 指纹被网络忽略 |
| M4 | 控制代理闭环 | B4 | wrong-object rate 相对下降 >=20% | CPU/GPU 2–8h | tracker gain 不改变策略 |
| M5 | 扩展 | B5 与真实 VLA 接口 | 仅 M1–M4 全通过 | 未预注册，需另立计划 | 工程范围膨胀 |

## Compute and Data Budget

- Pilot 估计：12–38 GPUh，低于当前 32 GPUh pilot 软上限的主体计划；超过 32 前只完成已启动种子并停止扩展。
- 数据：程序化生成的 MuJoCo 物理轨迹，保存在个人目录；不下载外部数据。
- 人工评估：无。
- 最大瓶颈：物理响应是否在强 tracking 条件下仍含身份信息，而非算力。

## Integrity Requirements

- 评测标签只能来自 MuJoCo 模拟器持久 body identity。
- 模型输入不得包含 body id、物性标签（oracle 版本除外并明确标记）或排列索引。
- train/validation/test 按 episode seed 与物性组合隔离。
- 预先保存每个 run 的 config、git/code hash、seed、原始 JSONL/NPZ 与聚合 CSV/JSON。
- 主结果至少 3 seeds，报告 bootstrap 95% CI；单次最好结果不能作为结论。

## Risks and Mitigations

- 场景太容易：以 crossing + long occlusion + identical appearance 组成困难集，并报告分层结果。
- 场景不现实：推动动作通过空间 pusher 接触产生，不能直接向已知 object ID 施力。
- oracle 过强：同时加入模型参数误差，并单列 learned predictor。
- 过度保守：报告 risk-coverage、abstention 和完成步数。
- 新颖性不足：即使 pilot 阳性，仍需再次查新；本轮不把系统拼接包装成论文。
