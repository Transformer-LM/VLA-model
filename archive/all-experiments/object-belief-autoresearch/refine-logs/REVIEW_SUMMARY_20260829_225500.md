# Method Review Summary

**Reviewer verdict**：6.2/10，REVISE。  
**Decision**：接受评审；不按原 B1 gate 启动正式实验，先修订主张、基线与泄漏协议。

## 关键问题

1. `phi_i` 来自历史，因此不能声称含有“完整历史之外”的新信息；它只能是对历史交互更有效、带不确定性的压缩。
2. 真值 mass/friction oracle 胜过共享动力学是构造性上界，不能支持方法。
3. 必须比较只读允许历史的 system-ID posterior 与读取相同完整历史的 action-conditioned recurrent tracker。
4. 必须封死 body order、slot index、物性唯一编码、检测排序和动作 target ID 等泄漏。
5. 方法主张只有在身份指标改善转化为 wrong-object decision 改善后才成立。

## 已采纳修改

- 主张改为“相对当前 pose/velocity 与有限阶外推，更有效地提取同一允许历史中的身份信息”。
- 三层比较：privileged GT-parameter ceiling、history-only system-ID、full-history GRU tracker。
- 地址到 MuJoCo body 的映射每 episode 随机；检测排列随机；35% heterogeneous episode 含重复物性；共享 encoder 无 per-body embedding。
- 增加 permutation-equivariance、property-position correlation、detection-order uniformity 与 duplicate-property 审计。
- 空间 pusher 只执行世界坐标轨迹，不向 object id 直接施力。
- 最终 method gate 改为：system-ID 相对 full-history tracker 绝对 ID gain >=3pp、wrong-object 相对下降 >=15%；后续代理闭环仍要求 >=20%。
- privileged oracle 仅决定是否存在 headroom，明确不能支持 IFB。

## 保留风险

即使 method gate 通过，核心仍接近 online system identification + MHT。它只能支持一个窄的 VLA 对象记忆应用命题，必须再次查新；若 system-ID 与 full-history tracker 等价，则 KILL。
