# 最终启动计划（v3）

1. 全新 `ifb_sanity_v3_2000.npz`：MuJoCo contact/no-pusher smoke 与 leakage audit；只要 audit 失败就停止。
2. 全新 `ifb_main_v3_12000.npz`：再次执行严格 audit；`hard_id` 是由 pose-only margin 与真实移动量预先定义的 model-independent 困难子集。
3. M1a：`shared` 与 `GT-property oracle` 各 3 个固定步数 seeds；在 `hard_id` gate，并同时报告普通 `heterogeneous_id`。
4. M1a 失败自动结束；通过后才运行 M1b。
5. M1b：`system_id`、`full_history`、`full_history_aux` 各 3 个固定步数 seeds；method 与两条 full-history 中更强者比较。
6. 所有正式 gate 检查唯一 seed、共同 dataset/code hash、相同 config/optimizer steps、baseline 参数量不小于 method、逐 seed 同方向。
7. 本轮通过只进入后续 ablation 规划，不自动声称论文结论，也不运行真实机器人或 pi0.5 微调。

数据真值仅来自 MuJoCo 持久 body identity；模型输入只含对象级 XY/velocity、空间 pusher action 与测试前因果历史。所有代码、数据、cache、日志、checkpoint 和结果均写入个人目录。
