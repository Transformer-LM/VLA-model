# Experiment Bridge Code Review

## Round 1

**Verdict**：BLOCKED before 12k.  
**Blockers**：symmetric-cube yaw privilege；system-ID latent hidden channel；property auxiliary supervision confound；fake target `e % n`；weak audit；non-unique seed gate；no hard identity subset。

## Revisions

- 删除模型和 assignment 中所有 yaw，仅使用可观察 XY 状态/效果。
- system-ID effect decoder 接收 detached property posterior moments；property encoder 只由 property NLL 训练，并报告 RMSE/NLL/coverage。
- 新增 `full_history_aux`，给予相同 property auxiliary supervision；与 `full_history` 中更强者比较。
- 主训练固定 optimizer steps，禁止变体独立 early-stop/cherry-pick。
- dataset 保存独立均匀的 `decision_target`，所有 split 使用同一目标。
- 新增 pusher contact/no-pusher control、address↔body mapping、split×regime independence、heterogeneous-only repeated physics、逐 episode permutation equivariance、hard-ID count 审计。
- summarizer 显式 `headroom|method` stage；按 `(variant,seed)` 唯一；检查 data/code hash、config、optimizer steps、参数量和逐 seed 增益方向。
- 使用全新 v3 数据与隔离结果目录。

## Round 2

**Verdict**：APPROVE_WITH_CAVEATS，可启动 12k gated run。  
**Caveat**：当前是受监督物性 posterior moments 的显式分解，不是 Monte Carlo Bayesian marginalization；阳性 claim 必须据此收窄。GT-property oracle 仅为 privileged headroom ceiling。
