# 最终方法提案：Interaction-Fingerprint Belief（IFB）

**日期**：2026-08-29  
**状态**：仅批准进入可证伪 pilot；尚不主张形成完整论文创新  
**路线关系**：OA-WAM 提供持久对象地址；EvoScene 提供“动作应更新 belief”的原则；IFB 只研究二者之间尚未被证明的一个机制缺口。

## 1. 问题锚点

长时操作中，VLA 可能先与某个对象发生交互，随后对象被遮挡、交叉或重新出现。视觉相似时，系统可能把已经取得的任务进度写到错误对象地址上。OA-WAM 的稳定地址假定初始化和持续绑定足够可靠；EvoScene 的动作更新是全局场景 latent，无法回答“刚才被推动的到底是哪一个实例”。

真正的问题不是让 VLA 多记几帧，而是：

> 已经自然执行的动作及其物理后果，能否在外观、三维位姿和运动历史之外，为对象身份恢复提供额外证据？

## 2. 核心假设

视觉相同的对象可能具有不同的质量、摩擦、内容物或顺应性。对象地址 `i` 维护由此前自然交互估计出的物理响应指纹 `phi_i`。执行动作块 `a_t` 后，效果模型预测该地址的响应分布：

`p(delta s | s_i, a_t, phi_i)`。

对象重现并产生无序检测集合 `Y={y_j}` 后，身份排列后验为：

`p(pi | Y, a_t, B_t) proportional to product_i p(y_{pi(i)} | s_i, a_t, phi_i) * p_app(y_{pi(i)}, addr_i)`。

系统保留多假设后验，而不是立刻写入单一硬身份。低置信度时只延迟进度写入；主动重新观察和动作恢复不属于第一阶段主方法。

## 3. 方法的唯一主增量

**持久的、对象特定的交互指纹进入动作条件身份关联。**

这必须与以下强组合基线比较：

- 外观特征 + 3D 位姿；
- 遮挡前速度/scene-flow 代理 + 多假设跟踪；
- 使用共享物理动力学、但没有对象特定指纹的 action-conditioned filter；
- 额外历史长度或更大 MLP 的匹配预算基线。

因此，本提案不把以下内容声称为创新：对象 slot、Bayesian tracker、action-conditioned transition、belief correction、candidate reranking 或恢复控制器。

## 4. 第一阶段系统边界

输入：对象级真值/检测状态、已执行的空间推动轨迹、遮挡前历史。  
输出：对象地址到重现检测的概率关联。  
场景：多对象推动、遮挡、交叉和重现；对象数量与布局随机，不绑定搬箱任务。  
策略：暂时冻结或不接入 pi0.5，先隔离身份机制。  
世界模型：轻量概率状态转移，不生成 RGB 视频。  
环境：MuJoCo 真实物理模拟；评测只使用模拟器真值身份，不使用另一个模型的伪标签。

## 5. 主要 claim 与反 claim

### C1（主要）

在视觉歧义、遮挡和对象交叉下，对象特定 action-effect 指纹能在强 pose/flow/action-conditioned tracking 基线之上提高身份恢复，并改善后续目标对象选择。

### C2（支持）

收益来自校准后的身份后验，而不是仅仅增加参数或使用更多历史。

### 必须排除的反解释

- 位姿和速度已经包含全部作用效果；
- oracle 物理参数有效，但学习出的指纹无效；
- 只在手工设置的一种推动场景有效；
- 提高 ID 指标却不改变 wrong-object decision；
- 置信度只是过度保守，靠拒绝所有样本取得表面收益。

## 6. Pilot 决策规则

进入 learned WAM 和 VLA 集成需要同时满足：

1. Oracle 指纹相对“共享 action-conditioned dynamics + pose/velocity MHT”在困难集身份准确率至少提高 5 个百分点；
2. learned 指纹保留 oracle 增益的至少 50%；
3. wrong-object decision rate 显著下降，且 risk-coverage 曲线不靠大面积拒绝取胜；
4. 三个随机种子方向一致，95% bootstrap 区间不跨越零增益。

任一关键条件失败，则停止 OA-WAM×EvoScene 大规模集成，并把结果记录为机制否证。物理属性完全相同的对象是预注册负对照：IFB 不应声称能凭空区分它们。

## 7. 与 OA-WAM / EvoScene 的结合方式

- OA-WAM 的 `addr_i`：作为被维护的持久身份键；其视觉 `content_i^t` 不是物理指纹。
- EvoScene 的 action-updated prior：改为对象级 `p(s_i^{t+1}, phi_i | s_i^t, phi_i, a_t)`。
- 新观测到达时：不是直接覆盖 memory，而是先在候选身份排列上做预测—观测更新。
- 只有后验可靠时，才把关系/进度写回长期任务 belief；纠错和恢复是通过 pilot 后的第二阶段。

## 8. 已知局限

该方向只在物理响应有区分度且过去发生过交互时成立；对于外观、几何、物性完全相同的对象，它不会创造身份信息。其新颖性仍为中等风险，因此今晚实验首先验证条件信息是否存在，而不是直接投入完整 RGB-D WAM 或 pi0.5 微调。
