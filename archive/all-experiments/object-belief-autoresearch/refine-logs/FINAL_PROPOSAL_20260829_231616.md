# 最终 pilot 提案：Supervised Interaction-Fingerprint Moments for Object Belief

**问题锚点**：长时 VLA 在视觉相同对象经过自然操作、遮挡、交叉和重现后，可能把任务进度写到错误对象地址。  
**OA-WAM 作用**：提供持久对象地址。  
**EvoScene 作用**：提供“已执行动作必须更新 belief”的原则。  
**待证伪增量**：显式的对象物性 posterior moments 是否比读取相同完整历史的 recurrent tracker 更有效地形成动作效果分布，并减少错误对象绑定。

因果顺序严格为：

`可见历史 H_i → 监督估计物性 posterior moments → 测试动作 → 遮挡 → 无序 XY 检测 → 身份排列 posterior`。

测试阶段不读取 mass/friction、body id、slot embedding 或 yaw。system-ID 的 property encoder 只由训练期 simulator property NLL 更新；effect loss 对 posterior moments 做 `detach`，不能把它变成任意历史编码通道。当前 pilot 将 posterior mean/log-scale 输入概率 effect decoder，属于 moment-conditioned approximation，不实现也不声称精确 Monte Carlo 边缘化。

最强基线读取完全相同的历史：`full_history` GRU 与接受相同 property auxiliary supervision 的 `full_history_aux`；method gate 自动选择二者中更强者。GT properties 只用于 privileged ceiling。

预注册 gate：

1. privileged oracle 在 `hard_id` 上相对 shared dynamics assignment >=5pp、wrong-target 更低且三个 paired seeds 均同方向；否则 KILL。
2. system-ID 相对最强 full-history baseline assignment >=3pp、wrong-target 相对下降 >=15%、三个 paired seeds 均同方向；否则 KILL。
3. 即使通过，也只支持“受监督物性分解在该模拟身份问题上有效”；不支持精确 Bayesian inference、完整 OA-WAM×EvoScene 系统或真实 VLA 成功率。
