# 修订提案：Uncertainty-Coupled Interaction-Fingerprint Belief

**问题**：对象在自然操作、遮挡、交叉和重现后，长期 VLA memory 可能把进度绑定到错误实例。  
**范围**：视觉歧义、物理响应存在差异且此前有过允许交互历史的多对象场景；不绑定搬箱。  
**状态**：进入廉价证伪，不宣称当前已具备论文新颖性。

## 唯一待验证增量

OA-WAM 式对象地址 `addr_i` 维护一个由测试时允许的、对象级因果历史 `H_i={(s,a,s')}` 估计的物性 posterior：

`q(phi_i | H_i) = N(mu_i, Sigma_i)`。

测试动作执行后、对象在遮挡后以无序检测集合 `Y` 重现。系统把物性 posterior 通过动作条件效果模型边缘化到身份排列后验：

`p(pi | Y,a,H) proportional to product_i integral p(y_{pi(i)} | s_i,a,phi_i) q(phi_i|H_i) d phi_i`。

与 full-history tracker 相比，两者读取完全相同的历史；差别只是 IFB 显式保留“对象物性及其不确定性 → 动作效果 → 身份排列”的概率因子分解。它不拥有更多信息。

## 因果时间线

`可见历史交互 H_i → 估计 q(phi_i|H_i) → 测试动作 → 遮挡 → 无序检测 → 身份后验`。

测试动作后的结果不能回流到测试前的 `phi_i`。模拟器 body id 只用于最终评测标签。

## 必须比较

1. pose/velocity + 多假设关联；
2. shared action-conditioned dynamics；
3. full-history GRU（读取与 IFB 相同完整历史，且参数不少于 IFB）；
4. history-only supervised system-ID posterior + effect likelihood（pilot IFB）；
5. GT mass/friction privileged ceiling（只测 headroom，不支持方法）；
6. shuffled history、重复物性、homogeneous physics 与 permutation-equivariance 负对照。

## 决策门

- Headroom gate：GT ceiling 相对 shared dynamics >=5pp 且 wrong-object 更低；否则 KILL。
- Method gate：history-only system-ID 相对 full-history GRU assignment >=3pp，wrong-object 相对下降 >=15%，三种训练 seed 方向一致；否则 KILL。
- Control gate：固定 coverage 下，代理闭环 wrong-object action 相对下降 >=20%，且不靠大量 abstention；否则不接入 pi0.5。

即使全部通过，也只说明显式概率分解在该问题上有价值；不能把 system identification、Bayesian tracking 或 OA-WAM×EvoScene 拼接本身声称为新颖。
