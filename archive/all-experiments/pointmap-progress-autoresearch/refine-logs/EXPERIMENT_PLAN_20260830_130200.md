# Experiment Plan

**Problem:** 在长时 VLA 已写入、且不再是当前子任务的 `inside/on` 关系上，验证对象相对 PointMap 是否优于完整 Depth 帧，并在后续严格配对实验中检验执行轨迹的条件价值。  
**Method thesis:** PointMap 只在它改变关系判断/撤销决策时才有价值；受控扰动只验证表示与回滚上限，动作条件结论必须来自物理执行和精确状态配对。  
**Date:** 2026-08-30

## Claim Map

| Claim | Why it matters | Minimum convincing evidence | Blocks |
|---|---|---|---|
| G0 诊断门：稀疏对象 PointMap 可替代完整 Depth 帧完成关系决策 | 决定是否值得继续投入几何 WAM | 跨任务五折中，PointMap 的 IMR@FRR5 不比 Depth 差超过 5 点、macro-F1 不差超过 3 点，且输入/延迟明显更低 | B0, B1 |
| C1 主张：\(\tau^{kin}\) 在冻结 aliasing population 上提供条件增益 | 唯一可能支持 WAM transition 的命题 | IMR@FRR5 相对下降≥10%、绝对下降≥5点，FRR≤5%，胜过无 trace/command，分层 shuffle 后增益消失 | B2, B3 |
| C2 支撑：typed retraction 改变闭环结果 | 防止把分类提升冒充机器人收益 | 通过 oracle recovery gate；learned filter 提高 recovery/final success，并减少错误全局回滚 | B4 |

反主张：收益只来自 simulator depth/instance mask、动作模板泄漏、接触反馈、更多参数、或恢复策略本身。

## Experiment Blocks

### B0: 数据与几何确定性预检（MUST-RUN）

- 任务：LIBERO 5 个跨场景 `inside/on` 任务，每任务 12 个 reset seeds。
- 事件：preserved、co-motion、camera-shift、invalidated、unobservable sensor mask、wrong-object。
- 观测：双视角 RGB、metric depth、instance mask、camera inverse projection、对象/容器 simulator pose。
- 核验：相同 task/seed 的事件必须共享完全一致的 pre-state；所有 preserved/wrong-object/unobservable 关系仍成立；invalidated 不成立；PointMap 特征有限；已知刚体平移的 PointMap centroid delta 中位误差≤2 cm。
- 失败解释：任何标签/投影/恢复错误均为管线错误，不得进入训练。

### B1: E0 表示必要性诊断（MUST-RUN）

- 切分：5-fold leave-one-task-family-out；下一 task family 作 validation，其余 3 个训练。
- 每折/模态 3 seeds：17、29、43。
- 系统：
  1. object-addressed RGB before/after CNN；
  2. object-addressed complete depth before/after CNN；
  3. sparse object-relative PointMap feature MLP；
  4. simulator relative-pose oracle MLP。
- 公平性：RGB/Depth/PointMap 使用相同 target/reference instance association；相同数据、fold、seed、epoch/early-stop 协议；记录参数和单样本延迟。
- 主要诊断指标：IMR@FRR5 与 achieved FRR；支持指标 macro-F1、decision error、Brier、ECE、unobservable recall、输入字节与延迟。
- G0 go gate：
  - oracle macro-F1≥0.75 且 achieved FRR≤5%，否则视为训练/标签设计失败；
  - PointMap mean IMR@FRR5 ≤ Depth + 0.05；
  - PointMap mean macro-F1 ≥ Depth - 0.03；
  - PointMap 输入字节至少下降 10×；
  - 若只在 simulator masks 下成立，结论仅是 oracle-headroom。
- 失败解释：若 Depth 明显更好，停止“PointMap 代替 Depth”的建议；若两者都差且 oracle 好，说明 learned representation 不足；若 oracle 也差，修复数据/任务定义。

### B2: E1 配对物理 action-effect（G0 通过后 MUST-RUN）

- 从完全相同 pre-state 运行脚本化物理动作；至少一个动作族通过 interaction-state variation 同时产生 preserved/invalidated。
- command 分布跨结果重叠；按 action family、duration、pre-geometry、visibility 匹配；SMD>0.1 时重匹配/propensity weighting。
- 记录 \(\tau^{cmd}\)、\(\tau^{kin}\)，反馈版 \(\tau^{fb}\) 仅作 appendix。
- 比较 observation-only、no-trace learned prior、within-stratum shuffled trace、command-only、kinematic trace、matched RGB、oracle。
- 决定性结果：在冻结 \(\mathcal A_r\) 上 C1 gate 全部通过。
- 失败解释：条件价值未建立，停止 E2/E3；不把 B1 工程收益改写成 WAM novelty。

### B3: E2 VLA 分布验证（B2 通过后 MUST-RUN）

- backbone：现有个人 StarVLA LIBERO checkpoint；π0.5 仅在本地已有匹配 checkpoint/数据时加入。
- 只允许 on-policy 新采样或 action chunk 的 exact-original-state replay；禁止 different-state replay。
- held-out action templates/task families；分层 shuffle；command shortcut balanced accuracy 必须≤60%。
- claim gate 同 B2，并要求 \(\tau^{kin}\) 胜过 \(\tau^{cmd}\)。

### B4: E3 typed rollback closed loop（B3 和 oracle recovery 通过后 MUST-RUN）

- 先运行 GT relation oracle：若 recovery success<20% 或 final-success gain<5点，停止 learned gate。
- 冻结 VLA/recovery 行为，比较 persistence、global rollback/reobserve、typed relation retract、learned filter。
- 指标：verifier correctness、recovery success、final success、false completion、wrong rollback、stagnation、latency；分开报告 verifier 与 policy recovery competence。

## Risks and Mitigations

- POT-VLA 高重叠：只保留历史非 active relation 与 trace conditional value 命题。
- E0 synthetic masking shortcut：unobservable 只评估 epistemic behavior，不支持 action claim；B2 使用物理/真实视角含混。
- PointMap 用 simulator mask：B1 仅 oracle-headroom；后续必须用 deployed learned depth/masks 重测。
- 小 task 数 CI 不稳：以 task-family cluster 为统计单位并报告全部 fold，不将 seed 当独立 task。
- 恢复策略失败：oracle gate 先行，避免错误归因给 verifier。
