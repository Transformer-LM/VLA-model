# ISRAC WAM Route Cards

| Axis | Frozen choice | Reason / falsifier |
|---|---|---|
| Compiler input | Simulator dynamic state, contact trace, native physical parameter schema | Privileged offline compiler only; never presented as deployable WAM observation |
| Compiler output | Frozen twin worlds + equality/activation/first-divergence certificate | Must be verifiable without loading target WAM |
| WAM representation under test | R4 task-centric latent dynamics first; R3/R1 later | Local LIBERO FastWAM config exists, but no honest local LIBERO checkpoint yet |
| WAM action role | U3 candidate evaluation / runtime correction | Ordinary future prediction without decision effect is out of scope |
| Policy coupling | Frozen StarVLA candidate chunks | Separates compiler evidence from policy retraining gains |
| Pair timing | Compile and hash before post-hoc WAM scoring | Prevents target-model adversarial leakage |
| Primary endpoint | Certified-pair yield under matched simulator calls | If random/grid/CMA/BO matches it, compiler novelty fails |
| Secondary endpoint | False transport, ranking inversion, correction harm on held-out feedback interfaces | If aliases do not selectively harm feedback methods, narrow to a simulator diagnostic |
| Deployment claim | None at present | Simulator certificate is not a real-robot safety guarantee |

Representation and control usage remain separate: ISRAC does not propose that privileged simulator contact/state should become the WAM latent, and it does not count better video reconstruction as a successful control result.
